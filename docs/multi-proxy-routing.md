# 多出口与模型账号顺序

## 模型指定账号

在模型优先账号设置中选择账号后，可拖动已选列表，或使用上下移动按钮调整顺序。点击应用并保存后，新请求按该模型配置的顺序选择可用账号；当前账号不可用或并发已满时继续尝试后面的账号。

历史规则没有显式排序时，继续使用原有账号优先级，不会自动把账号 ID 当作管理员排序。已有有效粘性会话和 `previous_response_id` 会话链仍保留原有绑定语义。

## 单账号多出口

编辑账号，在多出口中勾选代理并分别设置并发数量。账号额度、计费和凭据仍属于同一个账号，不因出口数量增加而变成独立额度。

- **线路优先级**：正整数越小越优先，`0` 为默认档，排在显式正整数之后。同一档按并发负载比例均衡。
- **均衡分发**：默认模式。所有出口优先级为 `0` 时沿用原来的并发均衡逻辑。
- **首字优先**：仅 OpenAI 多出口账号可显式启用。根据真实请求的返回模型、成功情况和首字时间调整选择顺序。它不会后台持续发送收费测速请求。

出口优先级不修改账号优先级，也不修改模型指定账号顺序。候选出口仍受各自并发上限约束。

## 业务出口与抓取出口

票据抓取界面中选择的节点用于抓取，账号的单出口或多出口配置用于实际请求。保存的抓取节点会供下一次手动或自动抓取使用，两种配置相互独立。

同一账号的多个业务出口仍可携带同一份已保存票据。抓取时看到的模型不是实际请求返回模型的保证；以实际响应中的模型字段为准。票据长度、节点名称或国家不能证明模型质量，也不能保证首字速度。

## 验证与回退

先在少量账号上启用，再按同一模型、相近输入和多个时间段比较首字时间与失败率。网络连通性测试的首字节耗时不等于生成首字时间。

需要恢复原有均衡方式时，选择“均衡分发”，并把各出口线路优先级设为 `0`。这不删除代理、不更换账号凭据，也不重新抓票据。
